🚀 POUR DÉMARRER (3 ÉTAPES SIMPLES)
════════════════════════════════════════════════════════════════════════

1️⃣ INSTALLER MONGODB

   Option A (Recommandé - Local):
   → https://www.mongodb.com/try/download/community
   → Télécharger et installer pour Windows
   → MongoDB démarre automatiquement comme service

   Option B (Cloud gratuit):
   → https://www.mongodb.com/cloud/atlas
   → Créer compte gratuit
   → Créer cluster gratuit
   → Copier l'URI dans .env


2️⃣ INSTALLER LES DÉPENDANCES

   Ouvrir un terminal dans ce dossier et exécuter:
   
   npm install


3️⃣ LANCER L'APPLICATION

   Option A (Simple):
   → Double-cliquer sur: DEMARRER_APPLICATION.bat

   Option B (Terminal):
   → npm run seed    (peupler la base de données)
   → npm run dev     (lancer le serveur)

   L'application s'ouvre automatiquement sur:
   http://localhost:3000

⚙️ CONFIGURATION GOOGLE OAUTH (OPTIONNEL)
════════════════════════════════════════════════════════════════════════

Pour activer la connexion avec Google:

1. Aller sur: https://console.cloud.google.com/
2. Créer un projet "CryptoConnect"
3. APIs & Services → Credentials
4. Create Credentials → OAuth client ID
5. Type: Web application
6. Origines autorisées: http://localhost:3000
7. URI de redirection: http://localhost:3000/api/auth/google/callback
8. Copier Client ID et Client Secret dans .env

Voir le fichier README.md pour les instructions détaillées.

🎯 WORKFLOW TYPIQUE ADMIN
════════════════════════════════════════════════════════════════════════

1. SE CONNECTER EN TANT QU'ADMIN
   POST /api/auth/login
   {
     "email": "admin@cryptoconnect.app",
     "password": "Admin@123456"
   }
   
   Récupérer le token JWT dans la réponse

2. VOIR LE DASHBOARD
   GET /api/admin/dashboard/stats
   Authorization: Bearer <token>

3. TRAITER UNE DEMANDE CLIENT
   a) Lister les demandes en attente
      GET /api/admin/requests?status=pending
   
   b) Voir les détails
      GET /api/admin/requests/:id
   
   c) S'assigner la demande
      POST /api/admin/requests/:id/assign
   
   d) Répondre et clôturer
      PATCH /api/admin/requests/:id
      {
        "status": "completed",
        "responseMessage": "Votre demande a été traitée..."
      }

4. VÉRIFIER UN KYC
   a) Lister les KYC en attente
      GET /api/admin/kyc?status=pending
   
   b) Voir les détails et documents
      GET /api/admin/kyc/:id
   
   c) Approuver ou rejeter
      POST /api/admin/kyc/:id/approve
      { "notes": "Documents conformes" }
      
      OU
      
      POST /api/admin/kyc/:id/reject
      {
        "rejectionReason": "Documents illisibles",
        "notes": "Demander de nouvelles photos"
      }

5. GÉRER UN UTILISATEUR
   a) Rechercher l'utilisateur
      GET /api/admin/users?search=email@example.com
   
   b) Voir son profil complet
      GET /api/admin/users/:id
   
   c) Suspendre le compte si nécessaire
      PATCH /api/admin/users/:id/status
      { "accountStatus": "suspended" }
